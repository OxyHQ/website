# Oxy website

Marketing site, docs and newsroom for Oxy: Vite + React SPA (`src/`), Express API plus MCP server (`server/`), build-time steps (`scripts/`). Single flat package, no workspaces.

## Commands

```bash
bun install
bun run dev                  # API (server/index.ts) and Vite together; predev syncs docs, changelog and generated CSS
bun run build                # tsc -b, vite build, prerender, then the post-build gates
bun run lint                 # biome check . && eslint .
bun run lint:fix             # biome --write
bunx tsc -b                  # the real typecheck (see Conventions)
bun run typecheck:server
bun run test:server
bun run db:generate          # drizzle SQL into server/db/migrations/
bun run validate:agents-md   # AGENTS.md byte budget
```

## Map

- `src/` SPA; `server/` API and MCP; `server/db/schema/` one file per domain; `scripts/` prerender, pagefind, docs and changelog sync, OG images.
- `docs/` procedures and design notes: [`agent-rules.md`](docs/agent-rules.md) (the full reasoned rules), [`SEARCH-INDEXING.md`](docs/SEARCH-INDEXING.md), [`MCP.md`](docs/MCP.md), [`brand-system.md`](docs/brand-system.md).

## Conventions that differ from defaults

Each is explained in [`docs/agent-rules.md`](docs/agent-rules.md).

- Typecheck with `bunx tsc -b`, not `tsc --noEmit`: the build uses `tsc -b` and sees errors the flat check misses.
- A new key in `src/lib/i18n/locales/` goes into all eleven locales, translated: the locale type requires every key.
- Colour comes only from Bloom tokens; never hand-write a palette or a colour in a product stylesheet (`src/styles/theme.generated.css` is generated by `scripts/generate-theme-css.ts`).
- Import `Link`/`NavLink` from `src/lib/navigation`, never react-router: canonical URLs end in `/` and a bare link publishes a redirect.
- `_redirects` never carries a `200` rewrite; the app keeps `createRoot`, not `hydrateRoot`.
- Primary keys are 24-char hex `_id` from `newObjectId()`; every list query ends on `_id`; use `inArray`, never a JS array in a raw `sql` fragment; map unique violations to 409 with `isUniqueViolation`.
- Multi-row replacements (pricing, testimonials, navigation, backup import) run in a transaction.
- Protected routes use `@oxy.so/core/server`; no local auth middleware. Site admin is `website.content.manage`, with no grants or id lists.
- First-party never asks people for permissions: this app acts for a person with `actingFor` on what oxy's first-party registry declares (oxy ADR 0066); permissions, scopes and consent are only for third parties.
- Validate deploy-time configuration before `app.listen()`, never inside `connectWithRetry`.
- Feature board: `active`, `featureBoard` and `acceptsProposals` on `TrackedRepo` are separate switches; the write credential is `FEATURE_BOARD_GITHUB_TOKEN`.
- Careers are read-only Clarity Jobs (`server/services/careers.ts`); there is no jobs table here.

## Boundaries

Never:

- Edit `.github/workflows/`, `Dockerfile*` or the reviewed-image pins without the owner (CODEOWNERS): they decide what production runs, and a changed workflow can hold every run at `action_required`.
- Treat a green deploy job as a deploy: the circuit breaker can roll back while the job passes. Check the primary deployment's `rolloutState`.
- Publish to npm from a laptop ([npm releases](https://github.com/OxyHQ/oxy/blob/main/docs/npm-releases.md)).

Ask first: changing a route's canonical URL, locale or redirect behaviour; adding a dependency.

## Testing

- Any change: `bun run lint` and `bunx tsc -b`.
- `server/` change: also `bun run typecheck:server` and `bun run test:server`.
- Theme, routing, prerender or SEO change: `bun run build` (its gates run the contract tests) and check in a real browser with JavaScript blocked, using the trailing-slash URL.
- Done means CI green on the PR; the gates are in `.github/workflows/checks.yml`.

## PRs and commits

One topic per PR against `main`; imperative subject. A change to `AGENTS.md` stays under its byte budget (`bun run validate:agents-md`) by moving detail to `docs/`.

## Secrets

Runtime secrets live in SSM under `/oxy/website-api/` and are the only copy; GitHub holds none. `.env.example` lists local names. Never print `DATABASE_URL` or any token.
