# Tools

The Oxy MCP server's tools are declared once in the server and published to Oxy as the website's capability catalog. Your MCP client receives the current list, with each tool's description and input and output schemas, when it connects. The reference below is generated from that same catalog.

Call `describe_access` first: it tells you whether the connected account is a website admin, which tools it can use, and which options each one takes.

## Access classes

| Class | Scope | Who can call it |
|---|---|---|
| Read | `website.read` | Any Oxy account. Non-admins get exactly what the public site serves (published content only), through the site's public API. |
| Read (admin) | `website.read` | Website admins only — data with no public equivalent, such as the media library, translations, referrals and tracked repositories. |
| Write (admin) | `website.write` | Website admins only. |

A filter a non-admin cannot use (drafts, inactive listings, `featured: false`, admin-only filters) is refused with `permission_denied` rather than ignored, so a result never looks complete when it is not. See [Authentication](/developers/docs/mcp/authentication) for the full rules.

## Inputs

Inputs are validated before anything runs, so a call with the wrong shape changes nothing. Identifiers are 24-character hexadecimal `_id` strings; slugs are lower-case words joined by dashes; dates are ISO dates; links are a site path starting with `/` or an `http(s)` URL. Lists take `page` (from 1) and `limit` (1–100, default 20).

- **`locale`** — reads that take it return content in that locale, with its translations applied, exactly as the site's localized pages do. A locale the site does not serve is an error, not a silent fallback.
- **`expectedUpdatedAt`** — pass the `updatedAt` you read. If someone changed the record since, nothing is written and the error `precondition_failed` carries the current `updatedAt`.
- **`dryRun`** — deletes and whole-list replacements report exactly what they would do (the record, the translations or references it would take with it, the list diff) without writing.
- **`idempotencyKey`** — every write accepts one. Retrying with the same key and the same input returns the first result without writing again, for 24 hours, even if the retry reaches another server; the same key with different input is refused with `idempotency_conflict`.

## Limits

Each account has a per-minute allowance shared by every server: a read costs 1, a write 5, and an upload, bulk upload or repository sync 25 (600 per minute by default). A call over the allowance fails with `rate_limited` and `retryAfterSeconds`. `describe_access` reports the current limits.

The server speaks MCP protocol revisions up to `2025-11-25`; a client that only speaks a newer revision is refused with a clear error.

## Results

A successful call returns JSON as text and as structured content. A list is `{ items }` or a paginated envelope such as `{ posts, total, page, pages }`; admins and non-admins get the same shape. Listings carry summaries without full article bodies unless you ask for `view: "full"`.

## Errors

A failed call returns `isError: true` with an `error` object: a stable `code`, a human-readable `message`, whether it is `retryable`, and sometimes `details` (for example the fields that failed validation, or the references that stop a delete). An unexpected failure carries a `reference` to quote instead of internal details — errors never contain stack traces, SQL or credentials.

| Code | Meaning |
|---|---|
| `invalid_request` | The input is not valid for this tool |
| `not_found` | The record does not exist, or is not visible to this account |
| `permission_denied` | This account cannot use this tool or filter |
| `conflict` | A unique value (such as a slug) is taken, or the record is in use |
| `idempotency_conflict` | The idempotency key was used with different input |
| `precondition_failed` | The record changed since the `expectedUpdatedAt` you sent |
| `request_too_large` | A file or payload is over its limit |
| `rate_limited` | Too many requests; retry later |
| `service_unavailable` | A dependency (such as a remote download) failed; retry later |
| `internal_error` | Unexpected failure; retry, and quote the reference if it persists |

## Discovery and status

| Tool | Access | Options | What it does |
|---|---|---|---|
| `describe_access` | Read (any account) | — | Describe what this connection can do: whether the acting account is a website admin, the scopes granted, and every tool grouped by domain with whether it is available to this account, whether it writes, whether it accepts an idempotency key, whether a plain repeat is safe, how to undo it, and the input limits. Call this first instead of discovering permissions by trial and error. |
| `get_mcp_status` | Read (any account) | — | Report whether the MCP service is healthy on the task answering: database readiness, capability catalog registration with Oxy (state, version, hash, last error) and the configured authorization server. Contains no secrets. |

## Pages, navigation, hero and settings

| Tool | Access | Options | What it does |
|---|---|---|---|
| `list_pages` | Read (admin) | — | List the CMS pages: _id, slug and title. |

| `upsert_page` | Write (admin) | `expectedUpdatedAt`, `idempotencyKey` | Create a page, or update the page with this slug. Only the fields you pass are written on an update. Pass expectedUpdatedAt when editing an existing page to refuse the write if it changed since you read it. |

| `update_settings` | Write (admin) | `expectedUpdatedAt`, `idempotencyKey` | Update site settings. Only the fields you pass change; `banner` is replaced as a whole. |
