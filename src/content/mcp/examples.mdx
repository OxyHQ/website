# Examples

These workflows can be dropped straight into a Claude session. Each assumes the Oxy MCP server is connected and you approved the connection on auth.oxy.so (see the [Quickstart](/developers/docs/mcp/quickstart)).

Examples marked **Admin** need the connection's active account to be a website admin. On any other account those requests are refused with a clear error; the reads still work and return the public content any visitor sees. See [Authentication](/developers/docs/mcp/authentication).

## Catch up on the newsroom

> List the ten most recent newsroom posts and give me a one-line summary of each.

Claude lists the posts and reads the ones it needs. On a non-admin account this is the published newsroom exactly as it appears on [oxy.so/newsroom](https://oxy.so/newsroom/).

## Find an open role

> Which open jobs are there in engineering, and where are they based?

A public read: any Oxy account can run it.

## Publish a newsroom post with a cover image

**Admin.** Turn a paragraph of copy into a newsroom entry with a cover image.

> Draft a newsroom post titled "Oxy ships native federation across every app". Categories: Engineering, Product. Tags: federation, fediverse. Summary in one sentence, body around 200 words with a `## Why this matters` section near the end. Use the cover image at `https://images.example.com/federation.jpg`, alt "Two clouds meeting in the middle". Keep it as a draft.

Claude creates the post as a draft, uploads the image to the media library and sets it as the cover. Once you have reviewed the draft:

> Publish it.

## Backfill cover images

**Admin.**

> Here is a JSON array of `{ slug, imageUrl, alt }`. Set each post's cover image from its URL and summarise which ones succeeded and which failed.

The result reports each item's outcome, so one broken URL does not hide the rest.

## Keep the changelog in sync with GitHub

**Admin.**

> List the tracked GitHub repositories and tell me which ones have not synced in the last 24 hours.

> Add `OxyHQ/Bloom` as a tracked repository with the default tags Feature and Design.

> Sync every active tracked repository now, then list the five most recent changelog entries.

The website also syncs releases on a schedule; these requests are for onboarding a new repository or picking up a release immediately.

## Translate the hero into Catalan

**Admin.**

1. > Create the locale `ca-ES`, English name "Catalan", native name "Català". Enable it but do not make it the default.
2. > Get the hero and show me the text fields to translate.
3. > Save the Catalan translation of the hero with every text field translated.
4. > Show me the Catalan hero translation next to the source text, and list any text field still untranslated.

Only fields that differ from the source need a translation; everything else falls back to the default locale. Saving one field later keeps the others: translations are merged unless you ask to replace them.

## Run a referral campaign

**Admin.**

> Create four referral codes:
> - `ALICE-2026` for Alice Chen, ambassador, active.
> - `BEN-2026` for Ben Patel, ambassador, active.
> - `CARLA-2026` for Carla Diaz, ambassador, active.
> - `DEV-PARTNER-A` for Acme Co., paid, 20% commission, landing page `/partners/acme`.

Duplicate codes are reported as errors. Later:

> Set `BEN-2026` to paused.

## Audit the media library

**Admin.**

> List every media item tagged "newsroom" that is not used as a cover or social image by any newsroom post, including drafts. Do not delete anything yet.

Claude pages through the media library and the posts, compares them and prints the unused items for review. Deleting media also removes the stored file and its thumbnails and cannot be undone, so confirm before asking for deletes.

## Build a custom agent

Programmatic agents connect to the same endpoint Claude uses, with an MCP SDK client that supports OAuth. The person the agent acts for approves it once on auth.oxy.so; the SDK keeps the tokens it receives. What the agent may do is decided by that person's active account, exactly as for Claude. See [Transports](/developers/docs/mcp/transports).
